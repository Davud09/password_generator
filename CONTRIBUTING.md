# Contributing

Thanks for your interest in contributing.

## Before you start

- Open an issue to discuss substantial changes before starting work.
- Never include real passwords, credentials, or other secrets in code, tests,
  screenshots, or issue reports.
- Keep changes focused and include tests for behavior you change.

## Development setup

The repository does not yet document its runtime or package manager. Follow the
setup instructions in [README.md](README.md) once they have been filled in.

## Pull requests

Before submitting a pull request:

1. Run the project's tests and linters.
2. Confirm that generated passwords are not printed or stored by tests.
3. Update the README or other documentation when behavior or setup changes.
4. Describe the change and any relevant security or privacy implications.
